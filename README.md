**«Книги та Винагороди»** — це сучасний інтерактивний вебзастосунок з гейміфікацією, розроблений для заохочення дітей до читання. Застосунок перетворює читання на захопливу гру: дитина читає книжки, фіксує прогрес за допомогою таймера, складає квізи на розуміння сюжету, змагається у лідерборді з друзями та заробляє золоті монети, які обмінюються на реальні винагороди від батьків!

👉 **[https://books-rewarded.web.app](https://books-rewarded.web.app)**

## ✨ Ключові Можливості та Функціонал

### 👨‍👩‍👧‍👦 1. Родинний акаунт та Безпека (Firebase Auth + Firestore)
* **Автентифікація батьків:** Реєстрація та вхід за допомогою Email + Пароля з можливістю підтвердження пошти та відновлення забутого пароля.
* **4-значний PIN-код батьків:** Захищає чутливі налаштування та підтвердження винагород від дітей.
* **Реальний час (Realtime Sync):** Усі зміни (додані книги, прочитані сторінки, досягнення) миттєво синхронізуються між пристроями батьків та дітей через Cloud Firestore.

---

### 🔗 2. Дитячий доступ за унікальним посиланням
* **Прямий доступ для дітей без пароля:** Батьки можуть скопіювати персональне посилання для кожної дитини (наприклад, `.../index.html?familyId=...&childId=...`).
* **Автоматичний вход у дитячий режим:** Дитина відкриває це посилання зі свого смартфона чи планшета й одразу потрапляє у свій читацький дашборд.

---

### 👧 3. Дитячий читацький дашборд (Kid Reader Dashboard)
* **📚 Книжкова полиця:** 
  * Режими відображення: **Сітка (Grid)**, **Компактний (Compact)** та **Список (List)**.
  * Фільтрація за статусом (**Заплановано ⏳**, **Читаю зараз 📖**, **Очікують квізу 🏆**, **Архів прочитаних ✅**).
  * Початкова сторінка читання та видалення книг з полиці.
* **🚀 Відкладений відлік дедлайну («Розпочинаю читати!»):**
  * Нові книги додаються у статус **«Заплановано»** (відлік днів та бонуси НЕ починаються, поки книга чекає).
  * При натисканні кнопки **«🚀 Розпочинаю читати!»** книга стає активною і розпочинається відлік бонусних днів!
* **⏱️ Інтерактивний Таймер Читання:**
  * Фіксація тривалості читацької сесії та вирахування швидкості (сторінок за годину).
* **🎯 Щоденний трекінг та Серія днів (Streak 🔥):**
  * Відстеження днів поспіль та щоденних норм.

---

### 👥 4. Соціальний хаб «Друзі-Читачі» (Reader Friends & Leaderboard)
* **Запрошення друзів:** Дитина може скопіювати та надіслати другу персональне запрошувальне посилання (`?addFriend=CODE`).
* **Читацький Лідерборд:** Таблиця успіхів з медалями (🥇, 🥈, 🥉), де дитина та її друзі бачать серію днів читання (стрік 🔥), кількість прочитаних книг 📚 та баланс монет 🪙.

---

### 🔍 5. Розумний Пошук та Авто-імпорт книг за посиланням
* **🇺🇦 Вбудований каталог українських бестселерів:** Миттєвий знаходження популярних книг (*«Тореадори з Васюківки»*, *«Гаррі Поттер»*, *«Чудове Чудовисько»*, *«Краще ніж у фільмах»*, *«Пес на ім'я Мані»* тощо) з обкладинками та обсягом сторінок.
* **🛒 Пошук в інтернет-магазинах України:** 1-клік швидкі кнопки для переходу до пошуку у **Yakaboo.ua**, **Книгарні «Є»** та **Vivat.com.ua**.
* **⚡ Розумний імпорт за посиланням:** Можливість вставити посилання на товар із Vivat чи Yakaboo — система сама витягне назву, автора, обсяг сторінок, обкладинку та анотацію!

---

### 🛡️ 6. Батьківський режим (Parent Admin Mode)
* **Керування дітьми:** Додавання профілів, вибір аватарів-маскотів, зміна балансу монет.
* **Управління книгами та винагородами:** Налаштування ціни за сторінку, денних норм та схвалення квізів.
* **🗑️ Видалення акаунту:** Можливість остаточно видалити родинний акаунт та дані за потреби.

## 🛠️ Технологічний Стек

* **Frontend:** Vanilla HTML5, CSS3 (Glassmorphism, Flexbox/Grid, CSS Variables), Modern JavaScript (ES6+).
* **Backend & Cloud Services:** 
  * [Firebase Authentication](https://firebase.google.com/products/auth) (Email/Password Auth).
  * [Cloud Firestore](https://firebase.google.com/products/firestore) (NoSQL Realtime Database).
  * [Firebase Hosting](https://firebase.google.com/products/hosting) (Fast Production CDN).
* **Icons & UI Assets:** Font Awesome 6, Google Fonts (Fredoka & Inter), DiceBear Avatars API.

## 💻 Локальний запуск проекту

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Books_Rewarded.git
   cd Books_Rewarded
   ```

2. **Запустіть локальний сервер:**
   Відкрийте `index.html` у браузері або скористайтесь Live Server у VS Code.

3. **Деплой у Firebase Hosting:**
   ```cmd
   cmd.exe /c "npx -y firebase-tools deploy --only hosting"
   ```
