**«Книги та Винагороди»** — це інтерактивний веб-додаток, створений для мотивації дітей читати більше та із захопленням. Застосунок перетворює процес читання на захопливу гру: дитина читає книги, фіксує прогрес за допомогою таймера, складає квізи на розуміння сюжету та отримує золоті монети, які можна обміняти на реальні винагороди чи подарунки від батьків!

> [!WARNING]
> 🚧 **Статус проекту:** Додаток зараз знаходиться у **фазі активної розробки**. На поточному етапі можливі тимчасові недоробки, обмеження або помилки. Ми активно працюємо над їх усуненням, і все буде виправлено та вдосконалено в найближчий час!

---


## ✨ Основні Можливості

### 👧 Дитячий режим (Kid Reader Dashboard)
* **📚 Інтерактивна книжкова полиця:**
  * Перегляд книг у трьох режимах: **Сітка (Grid)**, **Компактний (Compact)** та **Список (List)**.
  * Швидкий пошук за назвою або автором, фільтрація за статусом та сортування.
* **⏱️ Таймер читання:**
  * Вимірювання часу, проведеного за книгою.
  * Автоматичний розрахунок швидкості читання (сторінок на годину).
* **🎯 Прогрес та Трекінг:**
  * Візуальні прогрес-бари для кожної книги.
  * Відстеження щоденних норм та серії днів читання (**Streak** 🔥).
* **🏆 Квізи та Мотивація:**
  * Проходження коротких тестів (квізів) після завершення книги для перевірки засвоєного матеріалу.
  * Бонусна система за швидке виконання планів читання (до **+50%** монет).
* **🎁 Баланс монет та історія:**
  * Нарахування монет за прочитані сторінки та успішні квізи.
  * Архів прочитаних книг.

---

### 🛡️ Батьківський режим (Parent Mode)
* **🔐 Захист PIN-кодом:**
  * Безпечний вхід для батьків через 4-значний PIN-код (за замовчуванням `1234`).
* **👨‍👩‍👧‍👦 Керування профілями дітей:**
  * Створення та редагування профілів (ім'я, вік, кастомний аватар через DiceBear API).
* **📖 Налаштування книг та винагород:**
  * Додавання нових книг до полиці.
  * Встановлення вартості читання (монет за сторінку), щоденних норм та термінів читання.
  * Створення та редагування квізів для перевірки прочитаного.
* **🔔 Сповіщення та підтвердження:**
  * Перегляд сповіщень про пройдені квізи та досягнення дитини.
  * Управління балансом монет та видачею винагород.

## 🛠️ Технологічний Стек

* **Frontend Framework:** Vanilla JavaScript (ES6+) — Single Page Application (SPA) архітектура без зовнішніх важких фреймворків.
* **Styling:** Custom CSS3 із використанням змінних CSS, Flexbox/Grid layouts, Glassmorphism ефектів, анімацій та 3D-трансформацій карт.
* **Icons & Fonts:** 
  * [Font Awesome 6](https://fontawesome.com/) — векторні іконки.
  * [Google Fonts](https://fonts.google.com/) — шрифти *Fredoka* та *Inter*.
* **Avatars:** [DiceBear API](https://www.dicebear.com/) — динамічна генерація яскравих аватарів для дітей.
* **Data Storage:** `localStorage` — збереження стану додатку, списку книг, профілів та досягнень безпосередньо у браузері.

## 🚀 Швидкий запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/YOUR_USERNAME/Books_Rewarded.git
cd Books_Rewarded
```

### 2. Запуск додатку
Оскільки додаток написаний на чистому HTML/CSS/JS, він не потребує складного збирання або встановлення пакетів `npm`.

* **Варіант A:** Просто відкрийте файл `index.html` у будь-якому сучасному браузері.
* **Варіант B (Рекомендований):** Скористайтеся розширенням **Live Server** у VS Code або запустіть локальний сервер:
  ```bash
  npx serve .
  ```

> 🔑 **Пароль батьківського режиму за замовчуванням:** `1234`
